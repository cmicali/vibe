# Shared controls

This directory contains controls both apps draw identically. Platform shells own placement and visibility; a shared control owns its retained layers, visual state and animation behavior. Neither side imports `Audio/`.

## EqualizerIndicatorView

The playing-row marker owns five retained pill `CALayer`s. It never redraws a bitmap or path for live motion. A material level change updates only the affected layer's model `transform.scale.y` and replaces one keyed explicit Core Animation animation from the presentation scale. Core Animation interpolates at the display cadence without an app callback or property write for every displayed frame. Stable bounds make `layoutBars` a no-op, and the poll path never invalidates layout, its row, the waveform or any sibling view.

`EqualizerLevelSource` is deliberately producer-agnostic: it supplies a coherent level snapshot plus a monotonic sequence and accepts balanced demand. The control's 20–30 Hz poller only polls that snapshot and the staleness clock — a `CADisplayLink` on macOS 14+ and iOS, a tolerant `NSTimer` on macOS 13; the fallback is confined to `startLevelLink`'s `@available` else-branch, and dropping macOS 13 support means deleting that branch. Duplicate sequences perform no transaction or layer write. Target threshold and attack/release durations live in `EqualizerAnimationMath.h`; activity is the pure fail-closed decision in `EqualizerActivityRules.h`.

Both `audioOutputActive` and `presentationVisible` default to NO. The poller also requires a source, a window and nonempty geometry. Starting declares one consumer. When audio stops while the row remains materially visible, the control invalidates the poller and balances demand immediately, writes the collapsed model scales, then lets one keyed Core Animation release per noncollapsed bar finish at compositor cadence. That release owns no display link, FFT, timer, callback or completion. Visibility loss, detachment, empty geometry and source replacement cancel keyed animations and settle to dots immediately; source replacement releases the old source before requesting the new one.

`Audio/Levels/CLAUDE.md` owns production. `iOS/CLAUDE.md` and `Playlist/Mac/CLAUDE.md` own their material-visibility facts. Root `CLAUDE.md` owns the cross-directory guarantee tying them together.

## LoadingIndicator and LoadingIndicatorView

`LoadingIndicator` is one control across **two styles and both modes**: a faint full-width track, a solid filled head over `[0, fraction]`, and — waveform style only — a shimmer band sweeping the unfilled remainder; indeterminate is simply nothing filled. The waveform style is the hairline midline both waveform views draw (they own when to show it — `WaveformUI/CLAUDE.md` keeps its traps); the row style is a small round-ended pill for the 16pt number gutter, and **it builds no shimmer at all** (`hasShimmer`): a 16pt gutter has no room for a sweep to read as motion rather than flicker, so its indeterminate motion is a slow whole-pill alpha pulse (`pulseAlpha`) instead — a provider's transfer can sit indeterminate for a long time before its first real fraction, and a static pill there reads as a bar stuck at zero. Each style has exactly one indeterminate motion, both compositor-only; the first fill sample retires the pulse. Style changes metrics, not structure: `LoadingIndicatorMath.h` is the per-style table, and the one seam under test. **The waveform style's numbers are a regression fence** — pixel-identical to what the control drew before the row style existed.

`LoadingIndicatorView` is the row gutter's host, structured like `EqualizerIndicatorView` — `#if TARGET_OS_OSX` only for the superclass and the layout/appearance/backing hooks. It is much cheaper than the equalizer: the sweep is one repeating `CABasicAnimation` on one layer — no display link, no timer, no app-side per-frame callback, no path rebuild; the whole thing runs on the compositor. What it must not do is hold a live animation for a row nobody can see, so **`active` goes NO on cell reuse, on hiding, and on scroll-out** — the row wiring in `Playlist/Mac/` and `iOS/` owns that. `active = NO` tears everything down; `endSweepKeepingFill` is never used here (it is the waveform's "data landed mid-download" case, which has no row equivalent). The macOS empty-state line reads the waveform style's height and track alpha from the math header, so the empty line and the loading track cannot drift apart.
