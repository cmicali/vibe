Vibe is a file player. It bundles no music and has no account of its own.
It plays files on the device, in the reviewer's own cloud storage, or at a web
address the reviewer types into Open URL. It goes online only to fetch that
address, or to reach Dropbox if the reviewer connects it.

WHAT YOU WILL SEE ON FIRST LAUNCH

An empty playlist reading "Nothing to Play". That is correct, not a broken
build: iOS gives an app no access to a user's files until the user hands them
over, so there is nothing to show until you do one of the following. Any one
of the four is enough.

1. THE APP'S OWN FOLDER (no permission prompt)
   In the Files app, go to On My iPhone > Vibe and copy an audio file in.
   Return to Vibe, open the Files tab, and the file is there. Tap it to play.

2. OPEN A FOLDER FROM ANYWHERE (one system picker, no custom prompt)
   In Vibe, tap the Files tab and browse to any folder - iCloud Drive, On My
   iPhone, Dropbox, or any other Files provider. Tapping a folder loads every
   track in it as the playlist; tapping a single file loads that file. Then
   tap any row, or the play button in the strip above the tab bar, to start.
   The access comes from the system picker and is remembered, so it is asked
   once rather than per file.

3. THE SHARE SHEET
   From any app showing an audio file, share it to Vibe.

4. OPEN URL (no permission prompt for an https address)
   In Vibe, open the Files tab and tap Open URL. Paste this public https
   address of the sample track below, and tap Open:
   https://raw.githubusercontent.com/cmicali/vibe/main/Assets/app-store/Vibe-sample-track.mp4
   It starts playing while it downloads. The system's local-network prompt
   appears only for an address on the local network, such as
   http://192.168.1.5/song.mp3. It never appears for an https address on the
   internet.

Vibe-sample-track.mp4 is attached to this submission, if you would rather not
supply audio of your own: a 30-second tone, tagged, that any of the four
methods above will play.

FORMATS

MP3, MP2, AAC, M4A, MP4, AIFF/AIF, WAV/WAVE/BWF, FLAC, QTA. Playback is
AVAudioEngine and CoreAudio only - there is no third-party audio library.

THE HOME-SCREEN WIDGET

Add it the usual way: long-press the home screen, Edit, Add Widget, Vibe.

On a clean install it shows a placeholder until Vibe has played something at
least once. This is by design, not a failure: the widget is a separate process
that draws only the snapshot the app publishes into the shared app group, and
a fresh install has published nothing yet. Play one track and the widget fills
in with the artwork, the title, and a live waveform. Its buttons drive
transport in the app, and tapping the waveform seeks.

BACKGROUND AUDIO

UIBackgroundModes includes audio. Playback continues with the screen locked,
and the Lock Screen and Control Center show the current track with working
transport controls.

PRIVACY

No data is collected, no analytics, and no tracking. The only network
requests are the ones the reviewer asks for: the address typed into Open URL,
and Dropbox if connected. Vibe sends nothing else and has no servers of its
own. Plain http is allowed only to the local network. The one permission
prompt is the local-network one, and only for a local address. Beyond that,
Vibe asks for nothing but the file access granted through the system picker.
UIFileSharingEnabled is on so that method 1 above works. The folder it
exposes holds only what the user puts there.

Vibe is free and open source: https://github.com/cmicali/vibe
