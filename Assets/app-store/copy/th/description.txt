Vibe คือเครื่องเล่นที่รวดเร็วและมินิมอลสำหรับไฟล์เพลงของคุณ ไม่มีเอนจินจากภายนอก ไม่ต้องมีบัญชี ไม่ต้องสมัครสมาชิก เล่นเพลงที่คุณมีอยู่แล้ว ไม่ว่าจะเก็บไว้ที่ไหน

มุมมองรูปคลื่น
Vibe วาดทุกแทร็กเป็นรูปคลื่นเต็มความกว้างหน้าต่าง คลิกตรงไหนก็ได้เพื่อกระโดดไปยังจุดนั้น

รวดเร็ว
Vibe ถูกสร้างมาให้เล็กและเร็ว แท็ก ปกอัลบั้ม และรูปคลื่นถูกอ่านเบื้องหลังและเก็บแคชไว้ การเปิดครั้งต่อไปจึงทันที

ถอดรหัสโดย macOS
MP3, AAC, MP4/M4A, MP2, AIFF, WAV และ FLAC ทั้งหมดเล่นผ่าน API ของระบบ ไฟล์ lossless เล่นที่ความละเอียดเต็ม และรูปแบบกับอัตราสุ่มตัวอย่างของแต่ละแทร็กอยู่ข้างชื่อเพลง

ไม่มีคลังให้นำเข้า
ลากไฟล์หรือโฟลเดอร์มาวาง — จากดิสก์ของคุณ จาก iCloud Drive หรือ Dropbox — แล้วเล่นได้เลย ไม่มีฐานข้อมูลให้สร้างใหม่ ไม่มีคลังให้ดูแล ปกอัลบั้ม แท็ก และ BPM จะทยอยเติมเข้ามาขณะที่แทร็กแรกเล่นอยู่แล้ว

สร้างโดยคำนึงถึงดีเจ
Vibe มีเฟเดอร์ pitch สไตล์เครื่องเล่นแผ่นเสียง การวิเคราะห์ BPM และคีย์ การข้ามที่แม่นยำระดับห้องเพลง และ performance FX

ฟรีและโอเพนซอร์ส
Vibe ไม่เก็บข้อมูลใดๆ และไม่แสดงโฆษณา ซอร์สโค้ดทั้งหมดอยู่บน GitHub ภายใต้สัญญาอนุญาต Apache 2.0
