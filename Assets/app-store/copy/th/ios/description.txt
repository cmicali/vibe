Vibe คือเครื่องเล่นที่รวดเร็วและมินิมอลสำหรับไฟล์เพลงของคุณ

มุมมองรูปคลื่น
Vibe วาดทุกแทร็กเป็นรูปคลื่นเต็มรูปแบบ ลากเพื่อเลื่อนตำแหน่ง และปัดไปด้านข้างเพื่อเปลี่ยนแทร็ก

เล่นไฟล์ของคุณตรงๆ
เล่นไฟล์บน iPhone ของคุณ ใน iCloud Drive หรือใน Dropbox — จากแอปไฟล์ หรือจากตัวเลือกไฟล์ในตัว

ไม่มีคลังให้นำเข้า
ไม่มีฐานข้อมูลให้สร้างใหม่ และไม่มีอะไรต้องซิงค์

ถอดรหัสโดย iOS
MP3, AAC, MP4/M4A, MP2, AIFF, WAV และ FLAC ทั้งหมดเล่นผ่าน API ของระบบ ไฟล์ lossless เล่นที่ความละเอียดเต็ม

วิดเจ็ต
วิดเจ็ตขนาดเล็กและขนาดกลางแสดงแทร็กที่กำลังเล่นพร้อมปกอัลบั้มและรูปคลื่นที่คุณเลื่อนตำแหน่งได้

ฟรีและโอเพนซอร์ส
Vibe ไม่เก็บข้อมูลใดๆ และไม่แสดงโฆษณา ซอร์สโค้ดทั้งหมดอยู่บน GitHub ภายใต้สัญญาอนุญาต Apache 2.0
