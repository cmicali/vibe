Vibe คือเครื่องเล่นที่รวดเร็วและมินิมอลสำหรับไฟล์เพลงของคุณ

มุมมองรูปคลื่น
Vibe วาดทุกแทร็กเป็นรูปคลื่นเต็มความกว้างหน้าต่าง คลิกตรงไหนก็ได้เพื่อกระโดดไปยังจุดนั้น

รวดเร็ว
Vibe ถูกสร้างมาให้เล็กและเร็ว

เล่นไฟล์ของคุณตรงๆ
ลากไฟล์หรือโฟลเดอร์มาวาง — จากดิสก์ของคุณ จาก iCloud Drive หรือ Dropbox — แล้วเล่นได้เลย ไม่มีฐานข้อมูลให้สร้างใหม่ ไม่มีคลังให้ดูแล

เอนจินเสียงของ Vibe เอง
MP3, AAC, MP4/M4A, MP2, AIFF, WAV และ FLAC เล่นผ่านเอนจิน CoreAudio ของ Vibe เอง พร้อมการแปลงอัตราสุ่มตัวอย่างคุณภาพสูง

โหมด bit-perfect
โหมด bit-perfect ใช้อัตราสุ่มตัวอย่างของไฟล์เมื่ออุปกรณ์รองรับ โหมดเอ็กซ์คลูซีฟสงวนอุปกรณ์ไว้ให้ Vibe ใช้

สร้างโดยคำนึงถึงดีเจ
Vibe มีเฟเดอร์ pitch สไตล์เครื่องเล่นแผ่นเสียง การวิเคราะห์ BPM และคีย์ การข้ามที่แม่นยำระดับห้องเพลง และ performance FX

ฟรีและโอเพนซอร์ส
Vibe ไม่เก็บข้อมูลใดๆ และไม่แสดงโฆษณา ซอร์สโค้ดทั้งหมดอยู่บน GitHub ภายใต้สัญญาอนุญาต Apache 2.0
