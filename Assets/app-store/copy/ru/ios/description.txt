Vibe — быстрый, минималистичный плеер для ваших музыкальных файлов.

Волновая форма
Vibe рисует каждый трек полной волновой формой. Потяните по ней, чтобы перемотать, смахните вбок, чтобы сменить трек.

Просто играет ваши файлы
Играйте файлы на своём iPhone, в iCloud Drive или в Dropbox — из приложения «Файлы» или из встроенного выбора файлов.

Никакой медиатеки для импорта
Нет базы данных, которую нужно перестраивать, и нечего синхронизировать.

Декодирует iOS
MP3, AAC, MP4/M4A, MP2, AIFF, WAV и FLAC — все воспроизводятся через системные API. Файлы без потерь играют в полном разрешении.

Виджеты
Маленький и средний виджеты показывают текущий трек с обложкой и волновой формой, по которой можно перематывать.

Бесплатный и с открытым кодом
Vibe ничего не собирает и не показывает рекламу. Полный исходный код — на GitHub под лицензией Apache 2.0.
