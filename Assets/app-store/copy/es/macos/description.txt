Vibe es un reproductor rápido y minimalista para tus archivos de música.

Vista de forma de onda
Vibe dibuja cada pista como una forma de onda completa a lo ancho de la ventana. Haz clic en cualquier punto para saltar ahí.

Rápido
Vibe está hecho para ser pequeño y veloz.

Simplemente suena
Suelta un archivo o una carpeta —desde tu disco, iCloud Drive o Dropbox— y suena. No hay base de datos que reconstruir ni biblioteca que mantener.

El motor de audio propio de Vibe
MP3, AAC, MP4/M4A, MP2, AIFF, WAV y FLAC, reproducidos a través del motor CoreAudio propio de Vibe, con conversión de frecuencia de muestreo de alta calidad.

Modo bit-perfect
El modo bit-perfect ajusta la frecuencia de muestreo a la del archivo si el dispositivo la admite. El modo exclusivo reserva el dispositivo para Vibe.

Pensado para DJs
Vibe incluye control de pitch al estilo de un plato, análisis de BPM y tonalidad, saltos exactos por compases y FX de performance.

Gratis y de código abierto
Vibe no recopila nada y no muestra anuncios. Todo el código fuente está en GitHub bajo la licencia Apache 2.0.
