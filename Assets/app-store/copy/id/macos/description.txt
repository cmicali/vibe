Vibe adalah pemutar yang cepat dan minimal untuk file musik Anda. Tanpa engine pihak ketiga, tanpa akun, tanpa langganan. Putar musik yang sudah Anda miliki — di mana pun Anda menyimpannya.

Tampilan bentuk gelombang
Vibe menggambar setiap lagu sebagai bentuk gelombang penuh selebar jendela. Klik di mana saja padanya untuk melompat ke sana.

Cepat
Vibe dibuat agar kecil dan cepat. Tag, sampul, dan bentuk gelombang dibaca di latar belakang dan disimpan dalam cache, sehingga pembukaan berikutnya seketika.

Didekode oleh macOS
MP3, AAC, MP4/M4A, MP2, AIFF, WAV, dan FLAC, semuanya diputar lewat API sistem. File lossless diputar pada resolusi penuh, dan format serta laju sampel tiap lagu tertera di samping judulnya.

Tanpa pustaka untuk diimpor
Jatuhkan sebuah file atau folder — dari disk Anda, iCloud Drive, atau Dropbox — dan langsung diputar. Tidak ada basis data yang perlu dibangun ulang dan tidak ada pustaka yang perlu dikelola. Sampul, tag, dan BPM terisi di belakang Anda sementara lagu pertama sudah berjalan.

Dirancang dengan DJ dalam pikiran
Vibe punya kontrol pitch bergaya turntable, analisis BPM dan nada dasar, lompatan akurat per bar, dan FX performa.

Gratis dan sumber terbuka
Vibe tidak mengumpulkan apa pun dan tidak menampilkan iklan. Seluruh kode sumbernya ada di GitHub dengan lisensi Apache 2.0.
