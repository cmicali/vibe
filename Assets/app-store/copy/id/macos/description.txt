Vibe adalah pemutar yang cepat dan minimal untuk file musik Anda.

Tampilan bentuk gelombang
Vibe menggambar setiap lagu sebagai bentuk gelombang penuh selebar jendela. Klik di mana saja padanya untuk melompat ke sana.

Cepat
Vibe dibuat agar kecil dan cepat.

Cukup memutar file Anda
Jatuhkan sebuah file atau folder — dari disk Anda, iCloud Drive, atau Dropbox — dan langsung diputar. Tidak ada basis data yang perlu dibangun ulang dan tidak ada pustaka yang perlu dikelola.

Mesin audio milik Vibe sendiri
MP3, AAC, MP4/M4A, MP2, AIFF, WAV, dan FLAC, diputar lewat mesin CoreAudio milik Vibe sendiri, dengan konversi sample rate berkualitas tinggi.

Mode bit-perfect
Mode bit-perfect mengikuti sample rate file jika perangkat mendukungnya. Mode eksklusif mencadangkan perangkat untuk Vibe.

Dirancang dengan DJ dalam pikiran
Vibe punya kontrol pitch bergaya turntable, analisis BPM dan nada dasar, lompatan akurat per bar, dan FX performa.

Gratis dan sumber terbuka
Vibe tidak mengumpulkan apa pun dan tidak menampilkan iklan. Seluruh kode sumbernya ada di GitHub dengan lisensi Apache 2.0.
