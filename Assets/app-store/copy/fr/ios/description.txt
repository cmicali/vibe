Vibe est un lecteur rapide et minimaliste pour vos fichiers musicaux.

Vue en forme d’onde
Vibe dessine chaque morceau sous forme d’onde complète. Faites glisser pour vous déplacer, balayez pour changer de morceau.

Il lit simplement vos fichiers
Lisez vos fichiers sur votre iPhone, dans iCloud Drive ou dans Dropbox — depuis l’app Fichiers ou le sélecteur intégré.

Aucune bibliothèque à importer
Aucune base de données à reconstruire et rien à synchroniser.

Décodé par iOS
MP3, AAC, MP4/M4A, MP2, AIFF, WAV et FLAC, tous lus via les API du système. Les fichiers lossless sont lus en pleine résolution.

Widgets
Les widgets petit et moyen affichent le morceau en cours avec sa pochette et une forme d’onde que vous pouvez parcourir.

Gratuit et open source
Vibe ne collecte rien et n’affiche aucune publicité. L’intégralité du code source est sur GitHub sous licence Apache 2.0.
