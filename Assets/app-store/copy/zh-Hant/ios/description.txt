Vibe 是一款為你的音樂檔案打造的快速、極簡播放器。

波形檢視
Vibe 將每首曲目繪製成完整波形。拖移即可定位，左右滑動即可切換曲目。

直接播放你的檔案
播放 iPhone 上、iCloud 雲碟或 Dropbox 中的檔案 —— 從「檔案」App，或從內建的檔案選擇器。

無需匯入資料庫
沒有需要重建的資料庫，也沒有需要同步的內容。

由 iOS 解碼
MP3、AAC、MP4/M4A、MP2、AIFF、WAV 與 FLAC，全部透過系統 API 播放。無損檔案以完整精度播放。

小工具
小型與中型小工具顯示目前曲目的封面，以及可拖移定位的波形。

免費且開源
Vibe 不收集任何資訊，也不顯示廣告。完整原始碼以 Apache 2.0 授權發布在 GitHub 上。
