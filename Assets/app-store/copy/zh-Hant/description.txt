Vibe 是一款為你的音樂檔案打造的快速、極簡播放器。沒有第三方引擎，無需帳號，無需訂閱。播放你已經擁有的音樂，無論存放在哪裡。

波形檢視
Vibe 將每首曲目繪製成橫貫視窗的完整波形。點按波形上的任意位置即可跳轉。

快
Vibe 以小巧與快速為目標打造。標籤、封面與波形在背景讀取並快取，因此下次開啟是即時的。

由 macOS 解碼
MP3、AAC、MP4/M4A、MP2、AIFF、WAV 與 FLAC，全部透過系統 API 播放。無損檔案以完整精度播放，每首曲目的格式與取樣率就顯示在標題旁邊。

無需匯入資料庫
拖入一個檔案或檔案夾 —— 本機磁碟、iCloud 雲碟或 Dropbox 皆可 —— 音樂就開始播放。沒有需要重建的資料庫，也沒有需要打理的音樂庫。封面、標籤與 BPM 會在第一首曲目已經播放時陸續補齊。

為 DJ 而生
Vibe 提供唱盤式音高推桿、BPM 與調性分析、精確到小節的跳轉，以及演出 FX。

免費且開源
Vibe 不收集任何資訊，也不顯示廣告。完整原始碼以 Apache 2.0 授權發布在 GitHub 上。
