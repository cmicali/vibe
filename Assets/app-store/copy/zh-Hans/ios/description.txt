Vibe 是一款为你的音乐文件打造的快速、极简播放器。

波形视图
Vibe 将每首曲目绘制成完整波形。拖动即可定位，左右轻扫即可切换曲目。

直接播放你的文件
播放 iPhone 上、iCloud 云盘或 Dropbox 中的文件 —— 从“文件” App，或从内置的文件选择器。

无需导入资料库
没有需要重建的数据库，也没有需要同步的内容。

由 iOS 解码
MP3、AAC、MP4/M4A、MP2、AIFF、WAV 和 FLAC，全部通过系统 API 播放。无损文件以完整精度播放。

小组件
小尺寸和中尺寸小组件显示当前曲目的封面，以及可拖动定位的波形。

免费且开源
Vibe 不收集任何信息，也不显示广告。完整源代码以 Apache 2.0 许可证发布在 GitHub 上。
