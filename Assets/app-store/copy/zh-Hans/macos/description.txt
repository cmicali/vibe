Vibe 是一款为你的音乐文件打造的快速、极简播放器。没有第三方引擎，无需账户，无需订阅。播放你已经拥有的音乐，无论存放在哪里。

波形视图
Vibe 将每首曲目绘制成横贯窗口的完整波形。点按波形上的任意位置即可跳转。

快
Vibe 以小巧和快速为目标构建。标签、封面和波形在后台读取并缓存，因此下次打开是即时的。

由 macOS 解码
MP3、AAC、MP4/M4A、MP2、AIFF、WAV 和 FLAC，全部通过系统 API 播放。无损文件以完整精度播放，每首曲目的格式与采样率就显示在标题旁边。

无需导入资料库
拖入一个文件或文件夹 —— 本地磁盘、iCloud 云盘或 Dropbox 都可以 —— 音乐就开始播放。没有需要重建的数据库，也没有需要打理的资料库。封面、标签和 BPM 会在第一首曲目已经播放时陆续补齐。

为 DJ 而生
Vibe 提供唱盘式音高推子、BPM 与调性分析、精确到小节的跳转，以及演出 FX。

免费且开源
Vibe 不收集任何信息，也不显示广告。完整源代码以 Apache 2.0 许可证发布在 GitHub 上。
