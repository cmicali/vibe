This beta makes it easy to send everything needed to track down a problem,
in one file.

* New: Settings > Advanced > Debug info > Save… writes a text file with your
  settings, your audio devices and the formats they support, and this
  session's log, ready to attach to a bug report. It only reads; it changes
  nothing.
* This beta keeps more of its log, so the file includes what happened before
  you saved it. Save it before quitting Vibe.
* Fixed: with the Settings window open, a change in the bit-perfect status no
  longer makes the window recalculate its layout during playback.
