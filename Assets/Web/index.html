Vibe

A fast, minimal player for your music files.

Mac App Store Auto-updates Download v1.11 View on GitHub

macOS 13 Ventura or later · Apple silicon and Intel · Free and open source

Features

  • Waveform view

    Vibe draws every track as a full waveform across the window. Click anywhere on it to seek.

  • Fast

    Vibe is built to be small and fast. Tags, artwork, and waveforms are read in the background and cached, so the next open is instant.

  • Decoded by macOS

    MP3, AAC, MP4/M4A, MP2, AIFF, WAV, and FLAC files are played bit-perfect through the system APIs.

  • No library to import

    Drop a file or a folder from your disk, iCloud Drive, or Dropbox and it plays. No database to rebuild, no library to manage.

  • Built with DJs in mind

    Vibe includes turntable-style pitch control, BPM and key analysis, bar-accurate skips, and performance FX.

  • Speaks 30 languages

    Fully localized, from Bulgarian to Vietnamese.

Drop a folder, start playing

Drop audio files or a whole folder on the window or the dock icon. Artwork, tags, and BPM fill in behind you while the first track is already playing. Tab shows and hides the playlist; arrow keys select and Return plays.
